# 连续函数动画与单焦点字幕设计

## 目标

让武汉中考数学视频中的函数图像真正参与讲解：曲线生长、参数连续变化、顶点与投影线同步移动、追踪点沿曲线运动；同时让字幕、公式和图形形成单一视觉焦点。

## 设计

- 保留 HyperFrames + HTML/SVG/GSAP 的确定性渲染链路，不引入 Manim 或新运行时。
- `function-curve` 场景按“坐标轴出现 → 曲线从基线变形 → 追踪点沿曲线移动 → 顶点投影锁定 → 公式标注出现”编排。
- `parameter-sweep` 场景使用三组同构 SVG 路径，连续改变抛物线的水平位置和竖直位置；顶点、投影线和追踪点跟随同一时间轴移动。
- 去掉顶部整段 `narration` 的可见渲染，只保留底部 `subtitle` 作为字幕层；讲稿仍保存在 storyboard 和音频轨道中。
- 函数公式以靠近图形目标点的短标注呈现，不再固定占据画面中央。
- 非函数场景沿用现有中文深色舞台，但统一为单字幕层和分阶段公式揭示。

## 验收标准

- HTML 包含曲线路径变形、追踪点、顶点投影和连续时间轴钩子。
- HTML 不再渲染 `.narration` 可见层，底部字幕仍存在。
- HyperFrames check 运行时、布局、动画无错误；仅允许既有的时间轴密度提示。
- 真实样片关键帧能看到曲线形态/顶点位置变化，字幕不与顶部或中央内容争夺焦点。
