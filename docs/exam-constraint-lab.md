# 数学命题实验室：控制自由度与目标定解（第一阶段）

入口：登录后「动态几何实验室」→「数学命题实验室」。直接复用原有 /geometry-lab 路由、认证逻辑、样式变量，不新增导航栏、数据库表或网络 API。

## 核心区别

- **构型定解**：可行的几何对象仅剩一个。
- **目标定解**：几何对象仍可能有多个位置甚至连续运动，但目标长度、平方、面积等值相同。
- 非线性约束的局部自由度计算并不能直接证明全局唯一，第一阶段限定在三个可以**完全枚举离散解 / 解析证明不变量**的模型。
- 不接受未经验证的 AI 坐标、图形或最终答案；题干、图形和解析来自相同的参数。

## 场景与可改条件

1. **圆上的点（中考）**：x²+y²=r²（r 为 1–6 的整数）；可锁定 y∈[-7,7]，并筛选 x>0。目标可选 P 的坐标 / x²。算法通过精确整数差 r²−y² 判定无解、切线、一点、两点及无限多个点；坐标答案对非完全平方保留根式。
2. **抛物线交点（高考）**：y²=4px（p 为 1–3 的整数）；可锁定 x∈[-4,9]，并筛选 y>0。目标可选点 P / y²。通过 4px 的符号与平方根完整分类。
3. **三角形动点与定面积（中考）**：A(0,0)，B(b,0)，C 在 x 轴上方；可独立锁定 C 的高度和横坐标。只有高度固定时面积 S=bh/2 才唯一，即使点 C 仍可横向自由移动。固定横坐标是针对面积目标的冗余条件。

上述自由度属于规范坐标系中有限模型的内禀维数。状态展示 `continuous`、`none`、`unique`、`multiple`，特别区分无实数解与一个零根，以及「两个点但平方目标已唯一」。

## 出题流程

1. 先选择一个场景，然后调整标称参数。
2. 选中复选框，逐个将参数作为题设条件锁定。
3. 查看图形、可行解数量、构型自由度、目标是否唯一及冗余条件提示。
4. 目标唯一且可行时点击「根据当前条件生成一道题」，可展开推导和复制。
5. 条件改变后预览始终由当前状态计算，绝不从旧结果沿用标准答案。

## 安全边界和后续

第一阶段是教学/命题原型：既不修改学生正式练习、答题记录与分数，也不直接加入错题变式生成任务。不得声称具备任意图形中的完整约束求解能力。

后续可在明确验证范围和数据模型后，把结构化场景编译器接入练习任务；扩大到圆与圆、直线与二次函数、圆锥曲线弦长、动点最值等模板时，应分别给出可证明的实数解判定、边界条件及参数化验证。避免使用单次数值采样来证明“唯一”。
